# Cottages Kodaikanal website

Plain HTML, CSS and JavaScript. No build step: edit the `.html` files directly.

- Pages live in the project root (for example `car-rental-in-kodaikanal.html`).
- Styles are in `css/`, scripts in `js/`.
- The header and footer are shared and loaded from `partials/` by `js/include.js`. Change them once there.
- The enquiry form is shared in `partials/enquiry-form.html`.
- Vehicle and route pages share the `rides.css` and `rides.js` files.
- Each page keeps its own title, meta tags and schema in its `<head>`.
